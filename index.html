제안서 · 리포트 생성 도구

신규 브랜드 제안서(마켓 검증 · 시딩 캠페인 제안 등)에 필요한 정보를 정리해두면, 같은 형식으로 제안서를 만들 수 있습니다. TONYMOLY · LABIOTTE 제안서와 같은 틀을 사용합니다.
사용 방법
  1. 브랜드 정보와 시장 검증 요약을 입력하세요.
  2. 제안 조건(시딩 인원, 예산, 최소 팔로워 등)과 타임라인을 정리하세요.
  3. 참고할 PDF, 스크린샷, 브랜드 이미지를 업로드하세요.
  4. Export Brief로 파일을 내려받아 채팅에 업로드하면, 같은 템플릿으로 제안서를 만들어 드립니다.

사용 방법
  1. 캠페인 정보를 입력하고, 크리에이터별 콘텐츠 행을 채워주세요 (CSV 불러오기도 가능합니다).
  2. 수치를 입력하면 총 조회수 · 참여율 · Top Performer · 누락 데이터가 자동 계산됩니다.
  3. 증빙 스크린샷, GIF, 영상을 업로드하면 최종 리포트에 함께 표시됩니다.
  4. Generate HTML Report로 영상/GIF가 그대로 재생되는 단일 HTML 파일을 내려받거나, Print / Save PDF로 인쇄용 PDF를 만드세요.
